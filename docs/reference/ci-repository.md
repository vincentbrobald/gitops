# Platform CI repositories

> Reference · [Documentation](../../README.md#documentation)

The platform's own repositories whose pipelines Pipelines-as-Code runs on
the cluster: `gitops` (its merge checks), `gitops-scanner`, `pac-demo`,
`provider-forgejo`, `provider-artifact-keeper`. Teams' repositories get theirs
from the team chart ([What a team gets](team-resources.md#team-team-ci)). To
add one: [Add a platform CI repository](../how-to/add-a-platform-ci-repository.md).

## Files

| Path | Content |
|---|---|
| `clusters/lab/ci/<name>/repository.yaml` | the repository (below); the folder's name is the Repository's |
| `clusters/lab/ci/<name>/*.enc.yaml` | its Secrets (SOPS) |
| `clusters/lab/ci/<name>/kustomization.yaml`, `secret-generator.yaml` | generated by `tools/ci.py` |
| `base/ci-repository/` | the chart a `repository.yaml` is rendered with |
| `clusters/lab/addons/ci.yaml` | ApplicationSet `ci-repositories`: Application `ci-<name>` per folder |

## `repository.yaml`

Validated by `base/ci-repository/values.schema.json` (unknown keys refused).

| Key | Required | Description |
|---|---|---|
| `repository` | yes | `<owner>/<repo>` on Forgejo |
| `namespace` | yes | where its pipelines run; a lower-case DNS label, unique; listed in project `platform-services` |
| `pipelinesAsCode.settings` | no | the PaC Repository's `spec.settings`, e.g. `{pipelinerun_provenance: default_branch}` |
| `forgejo` | no | its Forgejo settings through Crossplane; omit when Ansible keeps them |
| `forgejo.repositoryId` | with `forgejo` | Forgejo's numeric ID (`GET /api/v1/repos/<owner>/<repo>`, field `id`) |
| `forgejo.collaborator.externalName` | no | `<id>/pac-bot`, when the collaborator exists already |
| `forgejo.webhook.externalName` | no | `<id>/<hook id>`, when the webhook exists already |
| `forgejo.deployKeys[]` | no | `name`, `title`, `readOnly`, `key`, `externalName` (`<id>/<key id>`) |
| `harbor` | no | its Harbor robot; omit for none |
| `harbor.project` | with `harbor` | the project (`registries/harbor/projects.yaml`) |
| `harbor.robot` | with `harbor` | the robot's name: `robot$<project>+<robot>` |

```yaml
repository: alice/gitops-scanner
namespace: gitops-scanner
pipelinesAsCode:
  settings: {}
forgejo:
  repositoryId: 10
  collaborator: {externalName: "10/pac-bot"}
  webhook: {externalName: "10/6"}
  deployKeys: [{name: push, title: push, readOnly: false, key: "ssh-ed25519 ...", externalName: "10/3"}]
harbor:
  project: gitops-scanner
  robot: gitops-scanner-ci
```

## What the chart makes, in `<namespace>`

| Object | When |
|---|---|
| the namespace (trust-manager adds ConfigMap `site-root-ca`) | always |
| PaC `Repository` `<name>` (status links to the platform's Tekton Dashboard) | always |
| pac-bot as write collaborator, the webhook to PaC, the deploy keys (Crossplane, never deleted) | with `forgejo` |
| robot account `harbor-ci` (password from Secret `registry-push`) | with `harbor` |

## Secrets

Made by `tools/ci.py generate` when missing:

| File | Secret | Content | When |
|---|---|---|---|
| `forgejo-pac.enc.yaml` | `forgejo-pac` | `provider.token` (pac-bot's token), `webhook.secret` (random) | always |
| `forgejo-webhook.enc.yaml` | `forgejo-webhook` | the webhook's config for Crossplane: `url`, `content_type`, `secret` (the same) | with `forgejo` |
| `registry-push.enc.yaml` | `registry-push` | `registry`, `username` (`robot$<project>+<robot>`), `password` (upper and lower case, a digit) | with `harbor` |

Other `*.enc.yaml` files in the folder (e.g. `argocd-preview` of `gitops`,
`dockerhub-push` of the two providers and gitops-scanner: Docker Hub
credentials, keys `username` and `token`, made by hand) are
listed by the generated `secret-generator.yaml` too.

## Settings kept by Ansible

| Repository | Why |
|---|---|
| `gitops` | Crossplane mustn't be able to lock the platform out of its own repository |
| `provider-forgejo` | Crossplane managing its own provider's repository would be circular |

Their Forgejo settings are in infra `forgejo.yml`.

## Removing a folder

| Goes | Stays |
|---|---|
| Application `ci-<name>`, the namespace, the PaC Repository, the Harbor robot | Forgejo collaborator, webhook, deploy keys (no `Delete`) |
